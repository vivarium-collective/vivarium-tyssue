# Stochastic line-tension experiments

A `tau` × `sigma` parameter sweep of the stochastic line-tension scenario: a flat
epithelial square sheet whose per-edge line tension fluctuates via an
Ornstein–Uhlenbeck process (`StochasticLineTension` + `EulerSolver`).

`tau` is the OU relaxation timescale and `sigma` the noise amplitude. For each
grid cell the script produces a colour-coded video, still frames, and an archived
simulation `History`, then quantifies two outcomes across the sweep:

- **Degree of stochastic vertex movement** — RMS per-step vertex displacement
  (and total path length per vertex), matched by `unique_id` across frames.
- **T1 transitions** — cell rearrangements where cells exchange neighbours,
  estimated by diffing the face-adjacency set (keyed by face `unique_id`) between
  consecutive frames.

## Run

Use the repo's `vivarium-tyssue` conda env (the `.venv`/`uv` are broken):

```bash
conda activate vivarium-tyssue
cd Experiments/stochastic_tension
python stochastic_tension.py
```

Requires ImageMagick (`magick`) on PATH for GIF rendering.

## Outputs (git-ignored)

```
data/test_square.hf5          # input mesh, copied from workspace/datasets on first run
outputs/
  tau0.10_sigma0.05/          # one dir per sweep cell
    stochastic.gif            #   edges coloured by live line_tension
    still_t*.png              #   4 still frames across the run
    history.hf5               #   archived simulation data
  metrics.csv                 # one row per (tau, sigma)
  summary/
    movement_heatmap.png
    t1_heatmap.png
    metric_vs_sigma.png
```

Nothing under `data/` or `outputs/` is tracked by git (see `.gitignore`) — the
sweep is fully regenerated by re-running the script. Tune the grid, `TF`, `DT` and
`SAVE_HISTORY` via the constants at the top of `stochastic_tension.py`.
